Retry authorization (verbatim): “Both authorized.” This authorizes exactly two

references Infrastructure's internal `IWorkerIntegrityLabeler`. Completing unique
assembly registration therefore requires a third product edit in
`src/Mcg.AgentOrchestrator.Infrastructure/Properties/AssemblyInfo.cs`; the retry's
explicit third-source-file stop condition leaves that edit unmade.

The routed focused check also reaches an unregistered sibling-project seam:
`GoalAcceptanceVerifier.ResolveDotnetTestRunner` classifies Dashboard.Tests as
VSTest rather than MTP. Correcting that requires a further product edit in
`src/Mcg.AgentOrchestrator.Infrastructure/Workspaces/GoalAcceptanceVerifier.cs`,
which is likewise outside this retry's authorization.

The negative controls remain: the shared project contains support but no test
methods; xUnit collection definitions remain assembly-local; the dashboard test
assembly uses the Infrastructure per-process temp-root bootstrap model; no product
behavior changes or product edits beyond those two registrations; and acceptance,
not the subscription worker, executes the test host.
