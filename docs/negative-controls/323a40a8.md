## Premise and asserted path

`AssemblyTempRedirect.BuildProcessTempRoot` is a pure function of its shared-root argument and process
id: it returns `Path.Combine(sharedRoot, $"p{processId:x}")`. The decomposed tests separately cover
that derivation, one launched host's layout/owner/log contract, and the two-host invariant. In the
two-host test, the first host remains live while the second starts and sweeps; the parent then asserts
that both roots still exist and retains the original case-insensitive distinct-root `Assert.False`.

The per-host readiness waits use each host's post-module-init event and the existing xUnit test timeout
only as a cancellable hang detector. There is no 30-second startup verdict. An early exit or hang names
the host whose receipt was not published, and `finally` releases and disposes both child processes.

`Path.Combine(sharedRoot, "shared-negative-control-root")` for every PID. To let both child processes
reach the parent assertion instead of failing in single-process setup, the child-only `p{pid:x}` shape
assertion was temporarily bypassed and each child used a PID-suffixed fixture subdirectory. Neither
parent assertion was changed.
