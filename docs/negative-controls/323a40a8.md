## Premise and asserted path

`AssemblyTempRedirect.BuildProcessTempRoot` is a pure function of its shared-root argument and process
id: it returns `Path.Combine(sharedRoot, $"p{processId:x}")`. The decomposed tests separately cover
that derivation, one launched host's layout/owner/log contract, and the two-host invariant. In the
two-host test, both hosts are launched before either receipt is awaited. Each publishes a post-module-init
receipt and remains live at the shared release gate; the parent then asserts that both roots still exist
and retains the original case-insensitive distinct-root `Assert.False`.

The per-host readiness waits use each host's post-module-init event and the existing xUnit test timeout
only as a cancellable hang detector. The child release gate has no elapsed-time verdict: it waits for
either the parent's named release event or the exact parent process handle to signal, so an aborted parent
cannot leave the child apphost orphaned. An early exit or hang names the host whose receipt was not published.
Before root survival is attributed to a sweep, the parent verifies that both hosts are still running; an
early exit reports its exit code and stderr. `finally` releases and disposes both child processes.
