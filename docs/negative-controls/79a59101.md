# Negative controls 79a59101

These controls correspond one-for-one with the four reductions recorded in
`docs/test-audit/79a59101.md`. The Developer role may compile but may not launch the test host;
the test-capable acceptance boundary must execute each mutation arm and the restored-code arm.
A compile receipt is not behavioral RED/GREEN evidence.

## RetryableLandingHold_PreservesPassingReceipt_AndLaterRelandsIdenticalState

- **Mutation:** in the identical-state cached-receipt path of `ConductorDriver`, reject or bypass
  the stored passing receipt after `LandingMutationBlocker` clears, forcing the verifier to run.
- **RED signature:** the configured verifier throws `InvalidOperationException` with “An
  identical-state landing retry must reuse its exact gate receipt”, or the retained
  `Assert.Equal(0, verifier.RunCount)` fails.
- **GREEN expectation:** restored code passes the method with both held and landed receipt
  assertions, exact tree/branch assertions, zero verifier runs, and cleanup assertions intact.

## ProductionRed_OneFailedMember_RequeuesGreenPeer

- **Mutation:** in cohort partition attribution, classify a combined RED with first-member RED and
  second-member GREEN as `BothMembersFailed` instead of `FirstMemberFailed`.
- **RED signature:** `Assert.Equal(AcceptanceCohortAttributionOutcome.FirstMemberFailed, ...)`
  fails; the second member's exact-one overtake assertions must not remain green accidentally.
- **GREEN expectation:** restored code passes the attribution, held outcome, unchanged-main, and
  idempotent overtake assertions with the same verifier sequence.

## ProductionBatch_SelectsRunsPersistsLandsAndCleansOneSharedCohort

- **Mutation:** in the successful production cohort batch path, skip cleanup of the shared cohort
  workspace after landing.
- **RED signature:** `AssertNoCohortWorkspaces(repo)` fails with at least one `c-*`, `p-*`, or
  `cohort-*` directory; the gate-run, landing, and persisted-evidence assertions still execute.
- **GREEN expectation:** restored code passes all assertions, including one verifier run, observed
  stable-slot lease, two advances, both landed files, persisted exit/TRX evidence, and no cohort
  workspaces.

## ProductionRed_RunsBothPartitions_AndClassifiesInteraction

- **Mutation:** when the combined cohort is RED and both member partitions are GREEN, return
  `FirstMemberFailed` rather than `InteractionOnly` and do not suppress the pair.
- **RED signature:** the retained `InteractionOnly` equality assertion fails and the suppressed-pair
  containment assertion fails after all three verifier invocations.
- **GREEN expectation:** restored code passes the failure outcome, interaction attribution, held
  members, unchanged `main`, cleanup, pair suppression, and two-partition-receipt assertions.
