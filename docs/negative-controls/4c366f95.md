# Negative controls: source-size preflight

The Developer lane may compile but may not execute the .NET test host. Before these tests count as gate
evidence, the acceptance lane must record these RED controls and then the final GREEN run:

- Bypass `SourceSizeRatchetPreflight` in `GoalAcceptanceVerifier.RunAsync`; the violating verifier test must
  fail because a process invocation or `build-server-shutdown` phase was observed.
- Bypass the conductor pre-slot call; the violating conductor test must fail because a lease was acquired or
  the acceptance callback ran.
- Remove either remediation phrase from the surfaced violation; the message assertions must fail on that
  missing phrase.
- Make the compliant fixture blocking; its test must fail because build-server shutdown was not entered.
- Make `AssertNoViolations` accept a non-empty result; `BackstopAssertion_ViolatingTable_GoesRed` must fail.

The RED receipt must name the failed assertion for each mutation; a compile result is not a substitute.
