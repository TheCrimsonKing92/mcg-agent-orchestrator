The fact then ran for 12.913 seconds before failing at its first process-dependent operation with `InvalidOperationException: Task ... has no background process to refresh.` Its stderr contained zero `temp-root-janitor` lines, one redirect timing line (`totalMs=49`), and one cleanup line (`elapsed_ms=144`). The assembly redirect could not be disabled separately: it is installed by `AssemblyTempRedirect.Install` as a module initializer and `WorkerDispatchTestSupport` has no disable seam. No support-only switch was added for this measurement. The available measurements reject redirect removal as dominant: the measured startup-plus-cleanup share was below 0.4% of the unchanged fact, far below the 50% threshold. No redirect code was changed.

The sampled fact's remaining duration is repository fixture work, not either mechanism named in this goal. The redirect-removal branch was therefore not taken.

## Safety control and outcome

The candidate then ran on the same path used by production, without detecting whether `TryKillPidTree` was overridden. The managed runner command was:

