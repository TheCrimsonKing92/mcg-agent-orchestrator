## Worker environment finding

**No. Workers do not receive an environment with the MCG_ identity and handoff variables removed.** This is a source finding about the launch construction path, not a live-worker observation.

The dispatch host starts from an inherited `ProcessStartInfo` environment in `src/Mcg.AgentOrchestrator.Execution/Processes/BackgroundDispatchRunner.cs:358`, with `MCG_DISPATCH_HOST_START_GATE` assigned at `src/Mcg.AgentOrchestrator.Execution/Processes/BackgroundDispatchRunner.cs:371`. The worker start info is built at `src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:1830` by `src/Mcg.AgentOrchestrator.Execution/Processes/WorkerProcessRunner.cs:30`. That constructor inherits the host environment; the helper applies the hook root at `src/Mcg.AgentOrchestrator.Execution/Processes/WorkerProcessRunner.cs:52`. Mandatory-context preflight rewrites command arguments (`src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:212`).

On Windows without the integrity sandbox, preparation configures PowerShell and Go caches (`src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:326`, `src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:327`). With the sandbox, it seeds provider homes and a CA bundle (`src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:438`, `src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:447`) and sets TEMP, TMP and PATH (`src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:453`, `src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:454`, `src/Mcg.AgentOrchestrator.Execution/Processes/DispatchProcessHost.cs:458`).
